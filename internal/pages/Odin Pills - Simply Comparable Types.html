What makes a type "simply comparable"?
Last modified 9/04/2026

When programming in Odin it is possible to run into a compiler saying that two types are not simply comparable.

Odin 
package simple_compare

My_Type :: struct {
	nums: []u8,
}

my_var1 := My_Type { {0, 1, 2} }
my_var2 := My_Type { {0, 1, 2} }

main :: proc() {
	assert(my_var1 == my_var2)
}
