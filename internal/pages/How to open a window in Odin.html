Odin Pills: Package names


Last modified 4/11/2024

Odin does not have a package in its core collection dedicated to window creation. This does not mean that you can’t create windows in Odin.

If you’re a beginner and this sounds confusing to you, you might want to learn about the concept of a foreign interface. It’s what allows code written in a programming language to call and be called by code written in another programming language. For example, it allows code written in Odin to call code written in C that has been compiled by a C compiler.

This means that if you know how to open a window in C, you really don’t need anything else. And wouldn’t you know it, there are plenty of ways to do it, because people have written many C libraries for it (e.g. SDL, Raylib) and all major desktop operating systems expose the functionality as C functions.
